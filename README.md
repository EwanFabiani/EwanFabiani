## Project pages

Add a Markdown file under `projects/` to make it available at
`/projects/<filename>/`. Use frontmatter to provide the page title, description,
and any number of custom links:

```markdown
---
title: Project name
description: A short description.
links:
  - label: GitHub
    url: https://github.com/EwanFabiani/project
  - label: Website
    url: https://example.com
---

# Project name

Project details go here.
```

The homepage's featured projects are configured by Markdown filename in
`featuredProjectFilenames` in `server.js`.
